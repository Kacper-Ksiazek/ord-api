### Errors & edge cases
| Status | When | Frontend action |
|--------|------|-----------------|
| `400` | `POST /api/v1/tts/speak` — blank or >5000 char `text` | Validate `text` length client-side before calling |
| `401` | `POST /api/v1/tts/speak` — no valid `AUTH-TOKEN` cookie | Ensure `withCredentials: true`; redirect to login |
| `502` | `POST /api/v1/tts/speak` — ElevenLabs unavailable or not configured server-side | Show fallback UI; retry or disable TTS playback |
| `400` | `POST /api/v1/quickly-added-words/ai/fill-gaps` — invalid request or no language proficiency | Validate `language` + `items` (1–20) before submit |
| `401` | `POST /api/v1/quickly-added-words/ai/fill-gaps` — unauthenticated | Same cookie-auth flow as other protected endpoints |
